# PokéStar

**PokéStar** est une application web interactive permettant de consulter rapidement les **forces et faiblesses des types Pokémon**.

L'objectif est de proposer une interface simple et intuitive pour comprendre les interactions entre les différents types de Pokémon et d'attaques.

## ✨ Fonctionnalités

* 🔍 Consultation des différents types Pokémon
* ⚔️ Visualisation des types **super efficaces**
* 🛡️ Visualisation des types **peu efficaces**
* ❌ Visualisation des types **sans effet**
* 📊 Affichage des relations entre les différents types
* 🎨 Interface web simple et responsive
* ⚡ Fonctionnement entièrement côté client

## 🧩 Technologies utilisées

* **HTML5** — Structure de la page
* **CSS3** — Mise en forme et interface
* **JavaScript** — Logique et interactions

Aucune dépendance externe n'est nécessaire pour utiliser le projet.

## 🚀 Installation

Clonez le dépôt :

```bash
git clone https://github.com/votre-utilisateur/pokestar.git
```

Accédez au dossier :

```bash
cd pokestar
```

Puis ouvrez simplement le fichier :

```text
index.html
```

dans votre navigateur.

Aucun serveur ou processus de compilation n'est nécessaire.

## 🎮 Utilisation

1. Ouvrez **PokéStar** dans votre navigateur.
2. Sélectionnez le type Pokémon ou le type d'attaque qui vous intéresse.
3. Consultez les interactions affichées.
4. Identifiez rapidement les types :

* 🟢 **Super efficaces**
* 🟡 **Peu efficaces**
* 🔴 **Sans effet**

## 📌 Objectif du projet

Ce projet a été réalisé afin de proposer un outil simple permettant de retrouver rapidement le **tableau des types Pokémon** sans avoir à consulter manuellement un tableau complexe.

Il peut également servir de projet d'entraînement pour la manipulation du **DOM**, des événements JavaScript et de la création d'interfaces web en HTML/CSS.
